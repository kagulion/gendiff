# Вычислитель отличий

## О программе

Вычислитель отличий (gendiff) — это программа, которая:

- принимает два файла с данными;
- сравнивает их содержимое;
- показывает, что изменилось между первой и второй версией.

По смыслу это похоже на git diff, но не для текста, а для структурированных данных (JSON, YAML).

## Зависимости

### Рабочие зависимости

- commander — для CLI
- js-yaml — для парсинга YAML

### Зависимости для разработки

- jest
- eslint
- prettier
