# Вычислитель отличий

## О программе

Вычислитель отличий (gendiff) — это программа, которая:

- принимает два файла с данными;
- сравнивает их содержимое;
- показывает, что изменилось между первой и второй версией.

По смыслу это похоже на git diff, но не для текста, а для структурированных данных (JSON, YAML).

## Зависимости

### Рабочие зависимости

- commander — для CLI
- js-yaml — для парсинга YAML

### Зависимости для разработки

- jest
- eslint
- prettier

## Структура проекта

```
project/
├── bin/                     // CLI
├── src/
│   ├── formatters/          // форматтеры
│   │   ├── stylish.js
│   │   ├── ...
│   ├── genDiff.js           // основа: файлы → объекты → diff
│   ├── diffObjects.js       // сравнение плоских объектов
│   ├── readFile.js          // чтение файла
│   ├── getFormat.js         // определение формата
│   ├── parsers.js           // Парсинг строки в JS-объект
│   └── loadData.js          // файл → JS-объект
├── __tests__/
├── package.json
└── package-lock.json
```
